# Android reference backend

Drop `{{crate_name | pascal_case}}BackendImpl.kt` next to your Activity /
Application and register the dispatcher:

```kotlin
IstmoRuntime.instance.registerHandler(
    {{crate_name | pascal_case}}Dispatcher.PLUGIN_ID,
    {{crate_name | pascal_case}}Dispatcher(
        backend = {{crate_name | pascal_case}}BackendImpl(context),
        codecs  = {{crate_name | pascal_case}}CodecsImpl(),
    ),
)
```

The `{{crate_name | pascal_case}}Dispatcher` / `{{crate_name | pascal_case}}CodecsImpl`
classes are generated by the consuming app's `build.rs` — they land under
`android/app/src/main/java/…/gen/` on every build.
