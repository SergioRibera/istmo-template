# iOS reference backend

`{{crate_name | pascal_case}}FactoryImpl` builds a
`{{crate_name | pascal_case}}BackendImpl` per client instance. Apps that
depend on this crate get this directory added to their target through
the generated `istmo-plugins.yml` xcodegen fragment, and the generated
`IstmoPluginRegistry` registers the factory (named by `ios_backend` in
`istmo.toml`) inside `IstmoApp.run()` — no manual wiring.

The `{{crate_name | pascal_case}}Backend` / `{{crate_name | pascal_case}}Factory`
protocols and the `{{crate_name | pascal_case}}Config` / `{{crate_name | pascal_case}}Error`
types are generated by the consuming app's `build.rs` from the Rust
trait.

Apps that build this backend themselves set `auto_register = false` for
this plugin and register it inside `IstmoApp.run(registerPlugins:entry:)`:

```swift
IstmoRuntime.shared.registerHandler(
    {{crate_name | pascal_case}}Dispatcher.PLUGIN_ID,
    {{crate_name | pascal_case}}Dispatcher(
        factory: {{crate_name | pascal_case}}FactoryImpl(),
        codecs: {{crate_name | pascal_case}}CodecsImpl()
    )
)
```
